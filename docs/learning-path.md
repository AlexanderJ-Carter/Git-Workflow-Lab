# 学习路径指南

本文档帮助你规划 Git Workflow Lab 的学习路线，根据你的水平和目标选择合适的课程。

> **编号 vs 顺序：** 关卡文件名编号（00–29）不变；**推荐学习顺序**以 [关卡总览](./lessons-overview.md) 中的逻辑阶段 **A–H** 为准。

---

## 逻辑阶段总览

```text
A 环境 ──→ B Git基础 ──→ C 分支协作 ──→ D 救火恢复 ──→ E 工程化 ──→ F CI/CD ──→ G 安全 ──→ H 进阶实用
00,00b      01–03         04–06b         07–09,20–21      13–17,22–23    10–12        18–19       24–29
```

---

## 按角色选择路径

### 新手

**适合人群：** 从未使用过 Git，或只会偶尔 `commit` / `push`

**学习目标：** 独立完成日常提交、拉取、查看历史

**推荐路径：**

```text
A: 00 → 00b → B: 01 → 02 → 03 → C: 04
安装配置   终端基础   新建仓库  暂存区   远程同步  分支入门
```

| 阶段 | 关卡 | 预计时间 |
|------|------|----------|
| A | 00, 00b | 45 分钟 |
| B | 01–03 | 2 小时 |
| C 入门 | 04 | 30 分钟 |

**预计总时间：** 约 3–4 小时

---

### 协作者

**适合人群：** 有 Git 基础，需要在团队中使用分支、PR、规范提交

**学习目标：** 分支开发、解决冲突、发起/审查 PR、约定式提交

**推荐路径：**

```text
C: 04 → 05 → 06 → 06a → 06b → E: 22 → 23
分支PR  冲突   rebase  SSH    协作规范  约定式提交  PR审查
```

| 阶段 | 关卡 | 预计时间 |
|------|------|----------|
| C | 04–06b | 3–4 小时 |
| E 协作 | 22–23 | 1 小时 |

**预计总时间：** 约 4–5 小时（含新手路径前置则更长）

**依赖关系：**

```text
04 ──→ 05 ──→ 06 ──→ 06b ──→ 22 ──→ 23
         │
         └──→ 06a（SSH，可与 06 并行）
```

---

### 救火工程师

**适合人群：** 经常需要恢复误操作、定位回归、并行 hotfix

**学习目标：** cherry-pick、reflog、stash、bisect、worktree、hotfix 发布

**推荐路径：**

```text
D: 07 → 08 → 09 → 20 → 21
    cherry-pick  reflog  stash  bisect  worktree

H: 25（hotfix 与 07 cherry-pick 联动）
```

| 阶段 | 关卡 | 预计时间 |
|------|------|----------|
| D | 07–09, 20–21 | 2.5–3 小时 |
| H hotfix | 25 | 35 分钟 |

**预计总时间：** 约 3–4 小时

**依赖关系：**

```text
04 ──→ 07 ──→ 08 ──→ 09
              │
              ├──→ 20 ──→ 21
              │
              └──→ 25（需 07 + 13 标签基础）
```

---

### CI 工程师

**适合人群：** 负责流水线、发布自动化、Secrets

**学习目标：** Gitea Actions、多阶段流水线、Release Please、安全实践

**推荐路径：**

```text
E: 13 → 17 → 22        F: 10 → 11 → 12        G: 19
标签发布 Release自动化  约定式提交   首个CI  修流水线  多阶段Secrets  Secrets安全
```

| 阶段 | 关卡 | 预计时间 |
|------|------|----------|
| E 发布 | 13, 17, 22 | 2 小时 |
| F | 10–12 | 3–4 小时 |
| G | 19 | 45 分钟 |

**预计总时间：** 约 6–7 小时

**依赖关系：**

```text
03 ──→ 10 ──→ 11 ──→ 12
              │
13 ──→ 17 ←── 22（约定式提交驱动 Release Please）
              │
              └──→ 19
```

---

### 进阶实用

**适合人群：** 参与开源、维护 monorepo、整理历史、大仓库优化

**学习目标：** fork 同步、submodule、交互式 rebase 进阶、历史考古、sparse checkout

**推荐路径：**

```text
前置: B(03) + C(06) + D(07) + E(16)

H: 24 → 25 → 26 → 27 → 28 → 29
fork/upstream  hotfix  submodule  rebase-fixup  blame考古  sparse-checkout
```

| 阶段 | 关卡 | 预计时间 |
|------|------|----------|
| H | 24–29 | 3.5–4 小时 |

**预计总时间：** 约 4–5 小时（含前置）

**依赖关系：**

```text
03 ──→ 24
06 ──→ 27
07 ──→ 25
16 ──→ 29
02 ──→ 28
```

## 学习建议

### 学习方法

1. **边看边做：** 打开课程文档，同时在 http://localhost:8080 终端和 http://localhost:3000 Gitea 操作
2. **完成验证清单：** 每课「如何确认自己做对了」务必逐项打勾
3. **用演示仓库：** `playground-hello` 练 Git 流程，`playground-ci` 练 CI/submodule
4. **按角色跳读：** 不必严格 00→29 数字顺序，按上表角色路径更高效

### 学习节奏

- 每次 1–2 课，隔天复习
- 阶段 D、H 建议在独立练习仓库实验，避免污染主分支

### 环境要求

- Docker + Docker Compose（`docker compose up -d`）
- 端口：8081（站点）、8080（终端）、3000（Gitea）、2222（SSH）
- 现代浏览器与代码编辑器
