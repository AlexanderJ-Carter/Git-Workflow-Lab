推荐学习顺序

如果你是 Git 新手，建议按照以下顺序学习：

  1. 阶段 A-B 环境与基础：安装配置、终端和 Git 基础闭环
  2. 阶段 C 分支与协作：分支、冲突、rebase、SSH 与协作约定
  3. 阶段 D 救火与恢复：cherry-pick、reflog、stash、bisect 与 worktree
  4. 阶段 E 工程化实践：标签、项目文件、Hooks、大仓库、发布规范与 PR 审查
  5. 阶段 F CI/CD：首个流水线、失败修复和多阶段 Secrets
  6. 阶段 G 安全：提交签名、标签签名与 Secrets 安全
  7. 阶段 H 进阶实用：Fork、hotfix、submodule、历史整理、考古与 sparse checkout
